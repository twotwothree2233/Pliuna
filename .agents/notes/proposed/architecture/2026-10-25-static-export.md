# Agent Note: 静态学习材料导出契约

Status: proposed

## Problem

独立材料需要离线分发，但交互页面含宿主执行能力、个人作答和版本化资源。直接保存页面可能泄露隐藏状态、混入不同版本或静默遗漏模拟器；导出时自动补齐还会带来未经选择的模型费用与副作用。

## Proposal

用户已整批确认，尚未实现。以 [导出契约](../../../../docs/harness/export.md) 为当前规范，首版只提供自包含静态 HTML，不携带自定义脚本或学习交互；已有内容转换打包，不执行模型/插件补齐。完整材料创作另开 Run。

显式分类、默认学习材料，附带正式作答/反馈需用户选择并绑定原题版本。不可拆混合片段从严，未分类进入完整性失败；分类不证明无隐私，预览提示保留。

固定快照、预览与成品一致，任务可继续更新但权限不冻结。缺失默认阻止；本人确认部分导出后成品在对应位置和清单注明遗漏。超限缩小范围，不静默转远程资源。

用户通过系统对话框选择位置，覆盖本人确认。临时生成校验后安全发布，失败保留原文件，取消清理未完成产物，不删除已成功文件。导出副本不随任务更新或删除撤回。

## 2026-10-26 契约细化

片段用稳定ID及本View根/独立静态片段，根重复或祖孙重叠拒绝，避免材料父节点泄漏个人子节点。允许选中的本地媒体内嵌原生离线播放，不自动播放/转码、不带自定义JS；它属于阅读消费而非学习提交。成品开发上限256MiB，实际离线编码和性能待测。

共同制品见[核心实现契约](../../../../docs/contracts/README.md)。本次是既有决定的细化，仍为 proposed，不宣称运行时已实现；结构校验与真实行为验证分开。

## Alternatives considered

- 保留本地脚本交互：表达力更强，但携带执行能力、离线依赖与故障风险，首版静态化，未来有明确需求再评估。
- HTML 加资源目录或 ZIP：可避免内嵌膨胀，但增加路径与分发复杂性，首版单文件并限制体积。
- 导出时自动补齐材料：一步得到完整成品，但引入不可预期费用与内容变化，改为用户另行发起 Run。
- 关键词/模型临时分类：少写声明，但不能可靠拆分混合内容或证明隐私安全，采用显式分类与预览。
- 导出期间一直读取最新内容：无需保存快照，但易混合版本，改为固定快照且可显式刷新。

## 历史审计

检索现有笔记未发现独立导出决定。[任务界面](2026-10-24-task-surface-contract.md) 与本篇部分重叠，继续保留呈现/受控边界，本篇收窄独立材料格式。[状态与恢复](2026-10-25-surface-state-and-recovery.md) 部分重叠，沿用不可变资源、静态历史和外部副本不撤回，不改写原取舍。插件信任、Monty 和上下文压缩决定无需替换；不将导出保存能力扩大为插件或计算 tool 的任意写文件权限。

## Acceptance criteria

- 单文件离线阅读，无脚本/自动外联/宿主依赖，不为导出调用模型或插件补齐。
- 分类、个人内容选择、原题版本绑定、缺失与部分导出本人确认可验证。
- 成品与预览版本一致；任务更新不混入，删除/撤权阻止未完成保存。
- 覆盖确认、磁盘失败与取消竞争测试不损坏原文件，不交付半成品冒充成功。
- 文档与笔记校验通过；真实浏览器/文件系统/平台测试仍待实现。

## Risks

内嵌资源增大文件，静态化降低表达力，声明分类不能证明无敏感信息。用户检查不能替代技术边界。跨平台替换、撤权与最终发布的竞争需实测；schema、体积限额和静态表示范围未定，不能宣称所有文件系统绝对原子或全部平台已支持。

后续细化：[任务停止与显式恢复](2026-10-25-task-stop-and-resume.md) 区分关闭页面、停止和恢复，要求新脚本区域发布附带静态表示；相关旧表述以该契约为准，原有独立取舍保留。

后续细化：[跨平台文件持久化](../../implemented/architecture/2026-11-07-platform-file-persistence.md)细化安全发布与双链接中断恢复。

# Agent Note: 任务停止与显式恢复边界

Status: proposed

## Problem

“任务关闭”混合页面可见性和执行生命周期，容易因切换页面中断生成，或让停止任务的旧结果继续提交。脚本区域静态表示可选，使停止执行后连必要题干都可能无法阅读。

## Proposal

用户已确认本批契约，当前仅文档落地，尚未实现。[运行时](../../../../docs/harness/runtime.md) 与[协议](../../../../docs/protocol-v0.1.md) 为当前规范。

关闭页面不停止执行。显式停止经任务写入协调先确立门禁，取消全部未完成请求、动作和审批，含无 Run 动作；随后清理模型、工具、脚本和任务级插件。已提交成果保留，迟到业务结果拒绝。全局插件只读保留、修改拒绝。清理完成进入已停止，异常如实展示，停止中禁止恢复。

停止期间用户仍可基础交互、保存草稿和明确提交答案，但不唤醒业务执行或积累恢复后队列。用户显式恢复只重新开放执行，可初始化当前有效脚本与可信插件、加载兼容状态，不恢复内存或重放旧请求/审批/工具/答案。插件代码和启动配置变化重新确认信任。

自定义脚本区域发布必须附带版本绑定的最低可读静态 HTML/CSS，用于停止、加载失败及历史。无须复刻交互或逐帧保存；重要实验结果显式持久化。结构安全不证明教学完整性，导出另检查分类和资源。

## Run 生命周期与结束清理

用户已整批批准六项细化，仍仅文档阶段。Run 使用运行中、等待中、已完成、已失败、已取消、已中断，原因单独记录；排队请求不提前建 Run。交还用户正常结束，问题留任务记录，不因等待回答占名额/配置；审批等待仍未结束。

所有结束路径先撤销继续提交资格并停止派发，有必要清理时仍为等待中，清理完成才终态并释放本 Run 占用，不影响其他占用者。清理异常不伪报成功，正常完成也不遗留获准关联工作。结束清理不可逆，迟到结果只补充事实，重试清理不重跑业务，不提供忽略清理恢复旧执行。

宿主确立结束边界时固定拟结束状态和首要原因，后续错误/取消只补充，不以跨进程时间戳改写。重启不等已消失的旧内存执行，废止旧许可并核对必要残留；已确立边界保留原因，其余未结束 Run 按中断收尾，不续跑。清理只涉及直接管理执行，不保证副作用撤回/全部后代终止。具体编码及清理接口未实现。

## 2026-10-26 契约细化

Run/Call/Action 状态及转换表已有编码草案，Action 四阶段、结果独立。必要清理失败有界退避后人工重试，无跳过入口；纯孤立文件删除不永久占执行名额。后台自动重启仅恢复读取和维护，不续跑业务。继续保留“已取消不代表副作用撤回”的理由。

共同制品见[核心实现契约](../../../../docs/contracts/README.md)。本次是既有决定的细化，仍为 proposed，不宣称运行时已实现；结构校验与真实行为验证分开。

## Alternatives considered

- 关闭页面即停止：含义直观但切换任务会意外中断生成，改为显式停止。
- 停止任务整体只读：门禁简单但阻断离线式学习，保留用户基础输入和作答保存，不放开插件/agent 修改。
- 恢复时续跑旧请求或积压作答：更连续但可能执行过时意图和授权，要求新请求。
- 等待进程退出后才停止生效：状态表面简单，但迟到输出可继续改变任务，先确立提交门禁。
- 静态表示可选：减少发布成本，但停止脚本后可能无法阅读必要内容，改为发布必需，保留损坏缺失的错误处理。

- 等用户回答仍保留活跃 Run：对话连续直观，但长期占名额/模型配置，交还用户正常结束并保存问题。
- 每种等待都建立生命周期状态：可直接显示细节，但状态随调度扩张，六状态加原因；排队请求与 Run 分开。
- 点击取消立即释放名额：响应快，但旧执行可能与新 Run 争用实例，先失效提交、清理后释放。
- 仅取消清理而失败/正常完成直接结束：实现分支较少，但可能遗留关联执行，统一收尾。
- 清理期间撤回取消或按迟到成功续跑：交互灵活，但复活失效许可，结束边界不可逆。
- 最后事件覆盖结束原因：能显示最新故障，但掩盖根因且受消息时序影响，固定首要原因并补充事实。

## Acceptance criteria

- 页面切换不停止，单 Run 取消和整个任务停止影响范围不同。
- 停止与提交竞态拒绝边界后旧结果，保留边界前提交；无 Run 动作同样撤销。
- 清理异常可见，停止中不可恢复，全局插件只读可用、修改拒绝。
- 停止时答案事务保存但不排推理队列；恢复不重放、初始化不自动提交。
- 缺少静态表示发布失败，历史与停止不运行旧脚本，损坏明确提示。
- 文档链接和 JSON 示例有效，真实运行时与浏览器测试待实现。

- 六状态及原因明确，排队不占位，交还用户结束，终态不可恢复。
- 各结束路径先失效后清理，清理前名额/配置保持，迟到结果不提交业务；重试仅清理。
- 原因按宿主结束边界固定，清理异常不覆盖，重启保留既定原因或按中断收尾，不续跑。
- 真实清理、状态持久化与竞争测试尚未实施。

## Risks

不保证撤回网络请求、外部副作用或终止插件全部后代进程。停止中异常的具体处置接口、状态编码尚待定义。静态表示有额外生成成本且宿主无法验证教学语义完整，不能把文档验收要求当成安全测试已通过。

后续细化：[插件内容形态与显式启用](2026-10-25-plugin-enablement.md) 限定后端进程要求、明确分类选择与配置占用；保留本篇独立取舍。

收尾失败会持续阻止同任务新 Run 和相关配置编辑，必须提供真实的维护清理反馈；不通过直接释放占用掩盖问题。结束边界/原因与崩溃恢复的持久化协调仍需实现验证。

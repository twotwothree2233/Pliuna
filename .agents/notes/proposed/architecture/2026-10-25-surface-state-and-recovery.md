# Agent Note: 表单状态与持久化恢复契约

Status: proposed

## Problem

单元更新、输入保存、正式作答和应用恢复需要一致语义，否则换题可能覆盖草稿、历史答案可能引用新内容，重启可能重复执行外部操作。已有架构只描述持久化方向，缺少用户已确认的失败和恢复规则。

## Proposal

本轮用户已确认，尚未实现。以 [存储与恢复](../../../../docs/harness/storage-recovery.md) 和 [任务界面](../../../../docs/harness/surface.md) 为当前规范。

呈现单元整体替换，普通内容为 HTML/CSS 加受限行为和状态声明。保留/重置显式选择，兼容版本与 schema、状态版本共同检查，不执行自动迁移。多表单提交限定字段；草稿宽松自动保存，提交严格结构校验，答案与事件事务保存，教学评分另行处理。

当前状态是恢复依据，保留必要历史而非完整事件溯源。重启恢复数据，不自动续跑 Run、插件调用或旧审批；用户继续开启新 Run，未知外部效果不重试。

资源副本不可变，先保存文件再提交引用；允许孤立文件安全回收。插件产物显式传输，不自动读取返回路径。保留已发布界面与答案，历史只读不执行脚本；人工确认永久删除，无回收站，清理中断可继续。

## 迁移与恢复点补充

用户确认数据库 schema 启动检查、维护期停止业务写入、先备份后受控向前迁移；失败阻止业务启动，旧版不自动降级。SQLite 一致性备份保存版本、必要非敏感配置及资源/插件副本引用清单，不明文导出凭据，不直接复制可能有未合并日志的数据库。关联文件受回收保护，不重复复制全部资源，迁移不原地改写或删除既有不可变资源。

最多一个有效恢复点，新候选创建并校验成功才替换旧点，失败保留旧点且不迁移，不按天过期；用户可明确删除。空间不足阻止迁移，不删唯一点，展示版本/时间/额外保留空间估算。恢复检查文件完整性，只恢复数据，不续跑旧执行，凭据缺失重新配置。

永久删除任务优先于迁移备份保留：确认连带影响后先废止包含任务的恢复点，再清理和释放引用，中断可续且不得恢复失效点。不修改备份内部剔除单任务，仍被其他任务/有效备份引用的文件保留。旧备份不能撤回失效判断，具体持久化方案待定义。无恢复点时不自动创建替代。本机迁移恢复不是灾备或介质擦除。

此为同一存储恢复决定的细化，原地补充，不改变已有不续跑、永久删除和不可变资源理由。

## 2026-10-26 契约细化

七轮契约补齐确认：managed-v1 违规内容拒绝而非静默清洗；保留丰富呈现，声明式直接行为不成为脚本语言。原始/正式答案分开，草稿只有内存及 SQLite 单一持久权威，版本冲突不自动合并。runtime 短事务、staging/pin、顺序分块不跨连接续传；必要执行清理与可延后磁盘 GC 分开。恢复旧数据本人确认。代价是中断上传重传、未保存输入崩溃可能丢失，收益是避免双份草稿恢复和过度传输协议。

共同制品见[核心实现契约](../../../../docs/contracts/README.md)。本次是既有决定的细化，仍为 proposed，不宣称运行时已实现；结构校验与真实行为验证分开。

## Alternatives considered

- 任意 DOM 修改：局部小改高效，但授权、恢复和状态保留更复杂，首版采用完整替换单元，本地交互自行处理。
- 完整事件溯源：重建能力强，但增加事件版本/投影/重放成本，不为当前单用户恢复需求采用。
- 自动续跑中断执行：体验连贯，但可能费用、过时审批和未知副作用重放，改为用户显式继续。
- 长期引用源路径：节省副本空间，但文件变化使历史含义漂移，改为不可变副本。
- 回收站：便于恢复误删，但引入保留期限与额外生命周期，首版人工确认后永久删除。
- 运行旧脚本重现历史：交互还原强，但可触发过时副作用，采用已保存静态表示与缺失提示。

- 每次完整复制全部资源：独立性更强，但大材料增加时间与空间，首版本机迁移恢复采用一致性数据库加引用保护。
- 永久保留所有恢复点：回退选择多，但持续占用资源，改为一个有效点且不按天过期。
- 保留含已删除任务的备份：保留升级恢复能力，但可复活永久删除数据，优先废止整个恢复点。
- 修改备份内部剔除任务：保留其他恢复内容，但破坏备份完整性与恢复依据，不采用。
- 自动降级或失败后继续部分迁移业务：减少阻塞，但兼容与数据一致性无法保证，拒绝启动并保留恢复入口。

## Acceptance criteria

- 草稿可保存不完整内容，正式提交只包含表单声明字段，答案快照和事件原子保存。
- 发布版本与状态兼容检查阻止覆盖新输入，丢弃必须本人确认。
- 重启无自动业务执行，旧许可失效，删除维护允许续清理。
- 资源副本和历史引用不可变，孤立回收避开在途保存，损坏明确报告。
- 历史只读无脚本执行，删除保护共享引用，插件路径不自动导入。
- 链接和示例通过文档校验；真实故障与行为测试仍待实现。

- 备份失败/磁盘不足不迁移、不删唯一恢复点；新点校验与替换崩溃边界需测试。
- 维护阶段无业务写入，一致性备份与引用保护有效；恢复不续跑，不明文导出凭据。
- 永久删除先废止相关恢复点，中断仍不可恢复且保护共享引用；旧版拒绝高版本数据库。

## Risks

兼容标识不能机械证明教学语义；崩溃可能丢失最后未保存输入。文件刷盘和数据库事务没有天然跨介质原子性，需测试。历史增加磁盘占用，回收保护尚待实现；表结构、上传字段与配额未定，不把文档当成可用 SDK。

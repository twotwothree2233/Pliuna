# Agent Note: 上下文压缩与模型中断边界

Status: proposed

## Problem

长期学习任务超出模型窗口后，摘要遗漏、工具记录截断或失败重放会改变学习事实和执行含义。插件还需要保留领域信息，但不能接管授权或把压缩变成另一套业务工作流。

## Proposal

用户已整批确认，尚未实现；当前规范见 [上下文管理](../../../../docs/harness/context-management.md) 与 [运行时](../../../../docs/harness/runtime.md)。研究仅为依据，不能把公开 agent 默认阈值直接变成本项目标准。

采用固定规则、工作摘要、最近完整交互与按需读取原记录。先减少装载和确定性缩减，再在请求前安全边界同步摘要。独立无工具请求默认使用主模型，成本纳入 Run，另配服务必须明确数据发送边界。

Harness 固定通用摘要结构，插件只能提供有界保留说明，不提供专用执行 hooks。摘要增量更新并保留来源，精确判断回查原记录；不删除原件、不代替授权、不做固定周期全历史重总结。

候选校验后才安装；可纠正问题最多纠正一次，失败结束 Run 保留数据，取消拒绝迟到摘要。过程可见、支持手动整理与详情，无专用摘要编辑器。无活跃 Run 的手动整理创建仅整理 Run，结束不触发业务动作。

模型部分输出中断不回滚已提交产物、不派发残缺调用、不重试未知副作用。仅无任何输出且暂时性错误才预算内有限重试；用户继续创建新 Run，不重放整轮。

## 2026-10-26 契约细化

宿主模板版本化、首版无编辑器，摘要 schema 及候选正文已起草；插件保留说明按实际使用记录确定性选择，不额外模型挑选。初始保留4完整交互组，输出预留8192与模型上限较小值，10%容量安全余量；容量未知仍禁止启用，usage校准不能伪装账单。具体提示词语义和估算器还需实验。

共同制品见[核心实现契约](../../../../docs/contracts/README.md)。本次是既有决定的细化，仍为 proposed，不宣称运行时已实现；结构校验与真实行为验证分开。

## Alternatives considered

- 并行后台压缩：可隐藏等待，但增加摘要过期、并发替换和未使用调用成本，首版同步执行；实测等待明显影响体验时再评估。
- 每次重总结全部原历史：有机会找回早期遗漏，但请求规模与成本持续增长，采用增量摘要、来源与局部修复。
- 独立廉价摘要模型作为必配项：可能降低费用，但增加配置与质量风险，默认主模型、允许显式另配并后续评测。
- 插件替换完整摘要提示词或执行 hooks：领域自由度高，但侵入宿主规则和压缩生命周期，采用有限保留说明，精确业务数据另存。
- 自动重跑中断整轮：交互省事，但可能重复副作用，保留已提交结果并由用户发起新 Run。

## 历史审计

[最小 Harness](2026-10-25-minimal-local-harness.md) 的简单 loop 与知识/授权分离继续有效，本篇细化上下文生命周期。[插件信任与归属](2026-10-25-plugin-trust-and-task-ownership.md) 部分重叠，保留注册读取级别和可信本地执行边界，压缩说明不是新的授权通道。[状态与恢复](2026-10-25-surface-state-and-recovery.md) 部分重叠，保留必要历史和新 Run 恢复，本篇补充模型网络中断。任务界面提案、Monty 选型及其快速测试与本次压缩决策无直接重叠，不重写或归档。

## Acceptance criteria

- 全输入预算、输出预留、交互配对与按需读取有确定性测试。
- 摘要失败/取消不覆盖有效上下文，不删除原件、不越权、不无限重试。
- 连续压缩测试用户纠正、未完成请求、来源与事实/推断区别，指标待评测确定。
- 手动整理不产生后续业务动作；部分流式失败不派发残缺调用或重复未知结果。
- 文档链接、JSON 示例与笔记结构校验通过，不能代替行为测试。

## Risks

同步压缩增加等待，主模型摘要增加费用。引用校验不证明语义正确，增量摘要可能累积遗漏；需要真实模型效果测试。预算、schema、提示词及快照安装实现未定。此处仍为 proposed，表示设计已确认但未实现。

# Agent Note: Agent 状态栏与任务正文分工

Status: implemented

## Problem

连续对话把长回复、审批、诊断和输入集中在窄侧栏。用户难以同时阅读正文和控制执行。用户认可修订方案 A：右栏只看状态与处理事项，输入固定右栏最底部，生成内容留在中间。

## Decision

`AgentPanel` 展示真实运行状态、当前任务和待处理概览。顶部状态与 Agent 同行；不从模型回复推断任务整体完成。模拟原型的用时和执行阶段不照搬，阶段只依据宿主已有事实。审批和界面替换在主动打开的详情中处理，多项逐一选择，参数完整读取与草稿丢弃确认沿用原约束。

`AgentActivity` 按当前任务和当前 Run 查询执行动态，替代固定的“请求已启动 / 执行结束 / 查看记录”三步。只读 `host.run.activity` 从持久记录投影本次指令预览与最近三项工具请求、结果或回复保存事件；不依赖近期混合事件窗口。指令最多 120 个 Unicode 字符，工具参数、结果正文与模型回复正文不返回侧栏。工具声明只说明已请求；缺少结果时显示待返回，Run 已结束时显示未取得结果。成功、未执行、失败、部分执行、取消与交付失败分别呈现；保存回复不意味着业务目标完成。查询失败提供主动重读入口，不退回模板事实。任务切换通过任务、Run 与 runtime epoch 隔离异步返回。

`RequestComposer` 继续挂载于右栏底部，材料折成一行，停止控制并入输入区。关闭、自动收起或调宽侧栏不销毁草稿和选中材料。队列历史分页与当前计数分离，`request.list.summary` 基于全量有效请求计算待处理数量。

中间内容页通过 `TaskReply` 展示最近保存的回复。新增只读 `host.messages.latest` 返回最新指令和最近回复的身份；正文通过原 `task.query/read message` 游标读取。它不扫描 renderer 的近期混合事件窗口，也不把最新回复声称为完整历史。普通读取最多缓存 256K 字符，超出转原消息分段入口。执行记录继续提供全部原消息与动作，查询不重放。

## Alternatives considered

- 保持右侧连续对话，操作与回复距离最近，但长文挤占状态和确认空间。用户已明确右栏用途是状态栏。
- 把输入区放在中间底部，便于围绕正文输入，但会挤占阅读高度。用户要求固定在右侧最底部。
- 直接搬近期快照中的消息最少改动，但混合事件窗口可能丢失消息，且长消息摘要截断。使用身份查询和已有完整读取接口。
- 用模型额外生成阶段摘要能贴近任务语义，但会增加调用、延迟和未经宿主确认的结论。侧栏直接由指令与动作元数据生成短条目；长文仍在正文，完整结果仍在原记录。

## Consequences

正文空间不再被输入框挤占，右栏只承担状态与控制。代价是审批与替换需要主动打开详情，当前内容只显示最近保存回复，历史仍需进入执行记录。审批提交后先关闭详情并禁用处理中入口，待新宿主状态返回再处理下一项。

新增宿主只读身份入口校验参数和任务归属，不读取正文、不增加模型工具。完整回复以安全纯文本显示，不执行模型 HTML；已发布 View 继续遵守原校验。超长回复超过 256K 字符转分段原消息入口，未自动读取所有历史。若后续需要多轮连续阅读，应扩展独立正文分页，不能退回混合事件快照。

动态条目只覆盖最近三项，完整过程继续在执行记录查看。动作标题来自工具类型与实际对象，未知工具退回通用名称，不从模型正文猜测成果。历史本机夹具没有模型 wire 记录时，仅从该 Run 的真实动作提供兼容显示；没有记录就不填步骤。查询接口严格校验任务与 Run 归属，不增加持久化格式或模型能力。

## Testing

类型检查与构建通过。41 项相关 Electron 用例均验证通过；最终整批 40 项通过，证据导出有一次 30 秒超时，单独重跑 8 秒通过。覆盖右栏无正文、底部输入几何、长中文回复完整读取和 HTML 文本安全、六主题、五字号、1440/720/390px、中文组合输入、关闭重开材料与草稿、未知结果暂停、材料范围、审批、替换与丢弃草稿、插件、上下文及执行记录。53 项查询、队列与同步单元测试通过，验证消息超出近期窗口仍可定位、参数与任务隔离、历史页不改变待处理计数。截图已核对。测试均使用隔离临时数据与本机合成服务，未调用外部模型。

动态投影经过 19 项查询测试与 3 项 Electron 定向测试验证，类型检查和构建通过。覆盖创建数据、读取数据、读取失败、纯问答、任务切换、近期窗口以外、同 Run 重复 wire id 配对、未返回结果、部分回复、交付失败、Unicode 预览上限与旧夹具动作；验证查询不重放、不返回正文或完整参数。定向界面测试同时核对六主题、五字号、三视口、中文输入、底部输入几何与原审批流程，动态界面截图已人工核对。

# Agent Note: 可关闭与调宽的三栏工作区

Status: implemented

## Problem

固定三栏不能按任务调整阅读和对话空间，旧窄窗断点也不能表达用户主动关闭。关闭面板若销毁子树，会丢失请求材料选择、局部展开和编辑器状态。用户确认方案 A，并确认两侧完全关闭、三栏可调和最小宽度保护。

## Decision

`workspace-layout.ts` 计算实际可用宽度中的三栏几何，`WorkspaceLayout.tsx` 管理关闭、抽屉、拖拽和键盘。默认左 220px、右 300px，中栏填满剩余空间；打开时最小左 180px、中 360px、右 280px。分隔线占 6px，关闭后该栏和分隔线都不占宽度。拖动一条分隔线只调整相邻侧栏和中栏；中栏随相邻边界变化，在最小值处停止。

空间不足先自动收起右栏，再收起左栏，左侧标题开关与 Agent 边缘入口可打开单个抽屉。自动收起不写回偏好，窗口扩大时恢复原宽；手动关闭则保持关闭。小于 360px 的极窄窗口让中栏适应可用宽度，避免制造横向溢出。尺寸与开关只在当前窗口内存保存，不新增设置文件或存储协议。

左右栏始终挂载，使用 `hidden` 隐藏；拖拽只更新几何，不替换任务编辑器。确认弹窗通过 `DialogFocus` portal 到 `document.body`，避免随侧栏一起隐藏。关闭不切换任务、不取消请求、不触发模型或审批。只读说明按需展开，未知提交结果和材料范围确认继续沿用原逻辑。

分隔线使用 pointer capture，按方向键每次 10px、Shift 50px，Home/End 到合法边界；双击恢复该侧默认，Esc/指针取消恢复本次拖拽前偏好。失焦释放拖拽。隐藏获得焦点的侧栏时把焦点交回对应开关。

设置与入口安排见[统一设置与渠道模型](2026-11-04-application-settings.md)。

## Alternatives considered

- 固定窗口断点配合纯 CSS 尺寸最简单，但无法同时表达任意拖拽和用户主动关闭，多个断点也不能保证三栏最小宽度总和。
- 关闭时卸载侧栏能减少隐藏树，但请求材料、导入状态和局部输入需要额外迁移；保留挂载更符合现有任务状态约束。
- 在拖动时重新发布整个任务界面容易复用现有渲染入口，但会重建编辑器和 Shadow DOM；几何独立于业务树，避免触发任务语义。

## Consequences

布局与业务树分离，关闭、调宽不损失草稿。代价是隐藏 Agent 的状态查询继续运行，并维护实际几何与用户偏好两层状态；当前窗口级偏好不跨重启保存。抽屉只负责显示，业务确认继续使用页面顶层弹窗。

历史笔记检索包含三栏、renderer、布局和草稿关键词。现有任务界面与恢复笔记描述业务 View/草稿协议，与本决定无重叠；本次不替代它们。视觉参考在 `docs/design/frontend-design.md` 同步布局规则。

## Testing

`tests/unit/workspace-layout.test.ts` 验证关闭占零宽、自动收起边界、最小值、中心重分和窗口组合不溢出。`tests/electron/workspace-layout.spec.ts` 验证真实鼠标、键盘、关闭重开、DOM/草稿保留、窄窗抽屉和六主题。构建和类型检查与桌面材料、审批回归一起验证；测试运行结果见当前任务报告。

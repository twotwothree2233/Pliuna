六套主题一览

六个方向共用同一套三栏布局与 token 命名。默认跟随系统：浅色用石墨，深色用暮色；其余四套作为可选主题保留。

状态清单

States

按钮

default → hover（亮度 1.07）→ focus（2px accent，offset 2）→ disabled（45%）。

输入

rest 1px line；focus accent + 3px accent-soft；禁用 55%；错误态暂用 warn。

列表行

rest 透明；hover --hover；selected --sel + --sel-fg；当前项左侧标记仅限支持的主题。

审批

pending = warn；approved = live + accent-soft；denied = line + muted。

弹层

点击遮罩 / Esc 关闭；打开后聚焦第一个控件；同一时间只保留一个。

深色

设置 color-scheme: dark；检查原生 select / radio / 滚动条；避免 #000。

所有 focus 状态必须可见；不要只用颜色区分选中与错误。深色主题需单独检查原生控件与滚动条。

06

实现约定

默认策略、token 骨架、主题边界与交付检查。照此实现即可保持六套视觉方向，而不把原型代码带进正式前端。

SYSTEM LIGHT→石墨 Graphite日间默认 · 系统 prefers-color-scheme: light
SYSTEM DARK→暮色 Dusk夜间默认 · 系统 prefers-color-scheme: dark
手动选择六套主题时覆盖系统；提供“恢复跟随系统”。持久化用户选择，但不要持久化临时预览。

建议

  • 所有组件只读语义 token；主题只覆盖变量。
  • 强调色只用于操作、当前项和图表曲线。
  • 暖纸的宋体只进入标题与阅读内容。
  • 蓝图用 1.5px 结构线、直角和等宽标签。
  • 苔原的标签与主按钮保持胶囊圆角。
  • 深色主题设置 color-scheme: dark。

避免

  • 在组件里写死颜色或单独覆盖主题。
  • 用强调色写正文，或大面积铺强调色。
  • 把宋体用在工具栏、状态栏和按钮上。
  • 给蓝图加软阴影、大圆角或渐变。
  • 在深色主题使用纯黑 #000 作为底色。
  • 只靠颜色表达选中、错误或审批状态。

交付检查

Handoff checklist
六套主题共用同一组 token 名，只覆盖值。
系统外观映射：浅色 → 石墨，深色 → 暮色。

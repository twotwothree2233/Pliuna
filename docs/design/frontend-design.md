# 前端设计参考

状态：视觉参考已确认；正式前端实现与验收尚未开始。  
更新：2026-10-26

## 1. 这份文档是什么

这是 Trellis 桌面端前端设计的视觉参考，用于正式实现时对照取值，不是生产代码，也不是组件库。

- **已确认**：Layout A 三栏布局、六套视觉方向、默认主题策略。
- **本文档负责**：颜色、字体、密度、圆角、组件视觉状态与主题差异。
- **本文档不负责**：运行时行为、业务规则、权限/审批语义、真实模型/文件/存储实现。
- 运行时行为以 [任务界面](../harness/surface.md) 为准；视觉稿不能替代其契约。

原型中的主题切换、新建任务、材料导入、审批和历史流程都是**交互示意**，只用于说明状态如何呈现，不代表已实现的业务逻辑。

## 2. 已确认基线

- 采用 **Layout A**：左侧任务列表 / 中间任务内容 / 右侧 Agent。
- **六套主题全部保留**：石墨、暖纸、深夜、暮色、苔原、蓝图。
- **默认跟随系统**：浅色使用石墨，深色使用暮色。
- 手动选择主题时覆盖系统设置，并提供“恢复跟随系统”。
- 主题只改变视觉语言，不改变布局结构、任务内容、权限或行为。
- 深色主题（深夜、暮色）启用 `color-scheme: dark`；其余为 light。
- 原型里主题属性为 `data-style`；正式实现建议统一为 `data-theme`，语义更清晰。

| `--fg` | `#23262a` | `#33302a` | `#e4e8ec` | `#dfe5e2` | `#2c362e` | `#101214` |

语义约定：

- `--bg` 是内容区背景；`--chrome` 是标题栏/状态栏；`--sidebar` 是任务列表；`--panel` 是 Agent / 设置面板。
- `--fg` 只用于主文字；正文用 `--muted`；占位和辅助说明用 `--quiet`。
- `--accent` 只用于操作、当前项、图表曲线；不要用它写长正文或大面积铺底。
- `--accent-soft` 是强调浅底与 focus ring；`--accent-ink` 是强调色上的文字。
- `--line` 用于普通分隔；`--line-strong` 用于需要强调的边界。
- `--sel` / `--sel-fg` 用于选中行；`--warn` / `--warn-bg` 用于审批与提醒；`--live` 用于就绪/成功。

字体栈：

```text
UI:    -apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC",
       "Hiragino Sans GB", "Microsoft YaHei", sans-serif
Serif: "Songti SC", "STSong", "Noto Serif SC", "Source Han Serif SC", Georgia, serif

```

- 暖纸的标题与阅读内容使用宋体；工具栏、状态栏、按钮仍使用 UI 字体。
- 蓝图的 view 标签、编号、版本号与元信息使用等宽字体。
- 其余主题标题/正文使用系统 UI；图表标注使用等宽，暖纸图表使用宋体。
- 标题栏高 48px（蓝图 46px）；工具栏 42px（蓝图 40px）；状态栏 26px；窗口边框 1px（蓝图 1.5px）。

## 6. 组件约定

完整尺寸与主题差异见 [设计 Token 对照 · 组件契约](assets/design-tokens.html#components)。实现时优先遵守：

| 组件 | 约定 |
| --- | --- |
| 侧栏 | 214px（蓝图 224px）；行高 31px；选中 `--sel`；左侧 2px `--accent`；蓝图改用 01/02 编号。 |
| 文档 | 最大宽度按上表；左右 40px；标题/导语层级固定；分节 28px + 26px。 |
| Agent | 300px（蓝图 312px）；消息 11px / 1.85；窄屏为覆盖抽屉。 |
| 主按钮 | `--accent` 底 + `--accent-ink` 字；6×10 内边距；`--radius-xs`；hover 亮度 1.07。苔原胶囊；蓝图直角 + 等宽大写。 |
| 标签 | 9px；2×7；圆角 3。苔原 999px 胶囊；蓝图 0 圆角 + 8px 等宽大写 + 1px 黑边。 |
| 输入 | 1px `--line`；`--radius-xs`；focus 用 accent + 3px accent-soft ring。深色主题启用 `color-scheme: dark`。 |
| 提示条 | 左侧 2px accent + accent-soft 底。苔原无左边框、圆角 10；暖纸衬线 11.5px。 |
| 审批 | 左侧 2px warn + warn-bg；approved 用 live/accent-soft；denied 用 line/muted。 |
| 弹层 | 最大 520px；圆角 `--radius`；遮罩 rgba(12,14,16,.3)；一次只开一个。 |
| 状态栏 | 26px；9px；`--chrome`；顶边 1px。蓝图等宽 8.5px + 1.5px 顶边。 |

状态必须实现：

- 按钮：default / hover / focus / disabled。
- 输入：rest / focus / disabled；错误态暂用 `--warn`。
- 列表行：rest / hover / selected；当前项左侧标记只在支持的主题使用。
- 审批：pending / approved / denied。
- 弹层：遮罩点击与 Escape 关闭；打开后聚焦第一个控件。
- 深色主题：检查原生 select、radio、滚动条；避免纯黑 `#000`。

## 7. 默认与实现约定

```text
prefers-color-scheme: light  →  石墨 Graphite
prefers-color-scheme: dark   →  暮色 Dusk
手动选择                     →  覆盖系统，持久化；可恢复“跟随系统”
```

- 所有组件只读语义 token；主题只覆盖变量，不写组件级颜色分支。
- 原型用 `data-style`；正式代码建议 `data-theme`。
- 深色主题在根节点设置 `color-scheme: dark`，并验证原生控件。
- 参考 HTML 中的 CSS 变量骨架只用于取值，不要直接复制 DOM 或状态逻辑。
- 正式实现请用 React/现有技术栈重建组件，视觉稿不是生产组件库。

## 8. 主题注意事项

- **石墨**：钢蓝只用于操作与当前项；1px 细线；阴影克制。
- **暖纸**：宋体只用于标题与正文；元信息下加细线；陶土色不做大面积填充。
- **深夜**：深色下启用 `color-scheme: dark`；标题栏轻微渐变；避免纯黑。
- **暮色**：比深夜更浅的炭灰；灰绿强调；与深夜二选一作为默认。
- **苔原**：标签与主按钮用胶囊；14/10/7 圆角统一；不要把边框加重。
- **蓝图**：1.5px 黑规则线、直角、等宽标签与编号；不要混软阴影或大圆角。

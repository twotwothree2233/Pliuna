# 任务界面

状态：行为与开发基线已确认；managed-v1 字段及初始允许表已有契约草案，浏览器实现、完整白名单验证和独立脚本容器仍待完成。

## 普通呈现：统一任务 DOM

Agent 可以生成自由组合的 HTML/CSS，由 harness 校验、处理并发布到其获准修改的呈现单元。共享 DOM 中不执行生成的任意 JavaScript。内容不必属于固定教学组件；限制作用于可执行行为和跨单元影响，而不是教学内容种类。

基础行为仅包括输入、选择、展开/隐藏、局部状态绑定和向 harness 提交事件。行为由宿主受信任代码实现，通过声明关联获准的本单元元素。不要扩展为包含任意表达式求值或动态代码执行的交互语言。

统一 DOM 使响应式布局、滚动、文本选择和普通浮层更自然。React 管理宿主界面，不意味着将未经处理的内容直接交给 dangerouslySetInnerHTML；必须使用经过验证的呈现入口。

## 自定义呈现：独立脚本区域

复杂算法、动画、图形模拟或特殊拖拽可以使用 HTML/CSS/JavaScript bundle，但只在隔离区域内部运行。不得操作父页面 DOM、其他 View、宿主存储或 Node API。跨区域协作只通过受控消息和显式授权。

不采用“每个呈现单元一个 WebContentsView”作为默认架构。具体隔离容器尚未锁定；iframe 等候选需要验证来源、导航、持久化、网络及资源耗尽风险。不得在隔离未完成时将脚本直接放到共享 DOM 中。

## 统一 DOM 的保护要求

范围授权不仅检查 DOM ID，还必须覆盖 HTML、CSS、URL 和行为配置：

- HTML 按允许列表处理；禁止脚本、事件处理属性、可执行 URL、嵌套任意活动文档和未批准浏览器能力。
- CSS 通过解析与作用域处理，不用正则替换冒充隔离。限制全局规则、导入、外部资源 URL、全局命名和越界定位，避免覆盖其他单元或宿主授权界面。
- 元素 ID、样式名称与行为目标在 View 内限定，不能使用任意全局选择器访问其他单元。
- 浮层、焦点和布局操作通过受控机制，不能通过无限 z-index、全屏覆盖或全局监听控制宿主。
- 网络资源只引用获准的本地资源；阻止隐式表单提交、远程字体、图片追踪和 CSS 外联。

这些要求可能限制部分 CSS 表达，但不能声称任意 HTML/CSS 在共享 DOM 中完全无影响。发布预览无法证明任意内容安全，仍需受限能力、事件配额和故障恢复。

## 所有权与发布

View 是任务持有的逻辑内容单元，不等于进程或独立网页。来源可记录参与插件，但不产生插件所有权或权限。插件停用后内容继续归任务保存，不需要转移所有权。

修改权由宿主授予具体执行方，限定区域、动作和布局范围。读取 skill 不增加权限；主 agent 的 Run 范围由宿主建立，插件按注册级别查询业务内容。所有修改走统一动作入口；无活跃 Run 时插件也可申请，待审批不占写队列，通过后排队复核。来源相同或内容归任务都不能绕过授权。

更新采用 inspect -> stage -> commit；变更集先检查再原子发布宿主界面模型，失败保留旧版。客户端按版本同步，不承诺所有像素瞬时切换。发布时再次检查权限与基础版本。插件间后端业务读取遵循注册级别，不能将前端 DOM 隔离误认为同任务数据保密。

## 更新粒度与状态兼容

首版只提供呈现单元创建、整体替换、移除和布局调整，不开放任意 DOM 节点编辑。替换一个单元不重建整页。按需拆分单元，减少大单元为小改动反复提交；输入、展开、滑块等即时交互在前端处理，不逐帧生成新版本。

内容和交互状态分开。替换必须明确 preserve 或 reset，不执行自动状态迁移代码。Preserve 要求单元 ID 不变、状态结构与兼容版本一致，使用当前已保存值，不用新初值覆盖。换题或字段含义变化必须更新兼容版本；同名 answer 不能证明仍是同一道题。

宿主校验结构和版本，但无法仅靠 schema 证明语义兼容；不能确定时拒绝自动保留。Reset 提供合法初值，丢弃用户作答/草稿必须由用户确认，不由审批模型代答。发布时再次检查状态版本，发现新输入先保存并重新检查，不覆盖。

## 声明式表单与输入

普通单元由 HTML、CSS、行为声明、状态声明组成。行为用稳定的本单元元素标识绑定字段和事件，不包含任意 JavaScript、表达式求值或全局选择器。状态声明包含结构、初值和兼容版本标识，字段草案见[managed-v1 契约](../contracts/managed-v1.md)。

一个单元可以有多个独立表单。提交按钮明确表单和可提交字段，不能默认提交整个单元状态；首版只选取声明字段，不在行为中计算表达式。图表参数、答案和备注不能无意混合提交。

## 草稿、提交与事件

输入先本地响应，再合并自动保存。基础草稿保存是用户操作的预先授权行为，不逐次审批、不推进学习流程、不唤醒 agent；插件或 agent 主动改写同样字段仍走动作检查。

草稿只检查允许字段、存储类型和大小，允许不完整输入，例如原始文本 `-` 或空的必填项。提交时前端提示并由宿主再次检查必填、数值格式、长度和范围；失败保留草稿和错误，不生成正式提交事件。正确性由 agent/插件教学评价，不因答案错误而阻止格式有效的提交。

用户明确提交后，宿主在同一数据库事务保存答案快照与对应事件，再确认接收；仅在任务允许业务执行时进入后续处理，停止期间只保存并标明尚未处理。快照关联内容/资源版本、表单和序号；后续草稿不改变它，再次明确提交产生新记录，不自动重发响应丢失的提交，再次提交是新操作。

显示保存中、已保存、保存失败；关闭/替换前先保存或由用户确认丢弃。不保证突发崩溃前每次按键都已持久化。通道来源认证、事件 schema/版本校验保持，不提供事件去重，被替换或移除区域的旧通道失效。

## 历史查看

保留已发布界面历史，草稿只保存最新值；未发布内容可清理。历史只读，不执行自定义脚本、调用插件或唤醒 agent。展示当时内容和作答，允许纯展示展开折叠，禁用提交修改；复杂区域使用静态表示，缺失明确提示。继续学习回到当前任务，不在旧版本上执行动作。

首版不建设完整历史编辑器、对比或任意版本回滚。持久化、资源发布与重启行为见 [存储与恢复](storage-recovery.md)。

## 网络和桥接

生成页面禁止直接外联。脚本、字体、图片和依赖随 bundle/宿主提供，不通过 CDN 加载。模型服务请求由后端处理，页面不持有密钥。

桥接只允许声明过的事件、受限状态操作和资源读取，不提供任意路径读取、任意 IPC 方法或任意工具派发。最终授权在可信宿主执行。

## 导出

首版导出固定快照的自包含静态 HTML，不保留自定义 JavaScript 或学习交互，不调用模型/插件补齐；允许基本阅读操作。复杂区域使用已有静态表示，折叠内容展开，移除提交与宿主执行入口。

内容显式分类，同一 View 可提供不同类别的可选导出片段，不要求拆成不同 View。默认学习材料，用户明确选择可附带正式作答/反馈并绑定当时题目版本；不可拆混合片段从严处理，未分类进入完整性问题。缺失时默认阻止，用户本人确认后才能部分导出且文件内标明遗漏。详见 [导出契约](export.md)。

## 停止状态与必需静态表示

自定义脚本区域发布时 MUST 同时提供经宿主校验、与内容版本绑定的静态 HTML/CSS；缺少表示则拒绝发布该区域，旧界面保留。静态表示至少提供必要说明、题干及阅读内容，动画/模拟/拖拽可用文字或图示说明交互不可用，不要求复制全部交互或每帧状态。宿主能检查存在性、结构及安全，不能保证教学语义完整。

静态表示用于任务停止、脚本加载失败及历史查看，导出仍另行检查分类与资源完整性。持久保存的实验结果或结论必须显式保存为任务数据或内容，不能只存在脚本内存。历史表示丢失或损坏仍明确提示，不通过执行旧代码补齐。

停止任务卸载脚本区域，但普通基础交互继续，草稿和正式答案可保存；正式提交不触发 agent/工具，也不排入恢复后自动执行的队列。停止后的当前界面不是历史只读页。打开页面不自动恢复；显式恢复可以重新初始化当前脚本、加载兼容的已保存状态，不恢复内存、不自动提交。完整时序见 [运行时](runtime.md)。

## 模型侧的统一写入入口

模型通过 read 查看界面对象/契约，通过 write 一次表达获准的界面变更，可包含多个现有操作并携带预期版本。stage、预览校验和 commit 是宿主内部流程，不要求模型逐步调用；插件协议/内部接口不因此删除。审批未完成不能报告已发布，冲突保留旧版、不自动合并。View 移除不删除历史或底层资源，不开放任意 DOM/JSON Patch。见 [工具与资源](tools-resources.md)。

## 引用任务数据的快照

界面提交明确声明采用的任务数据对象与预期版本，宿主在提交时校验并保存所需不可变快照，与发布内容绑定；版本变化拒绝并要求重读，不静默依赖最新值。源对象后续更新/移除不改变历史显示依据，资源引用继续保留。此内部固化不新增模型工具、不修改源对象，也不把界面发布扩展为任意跨对象事务。

## Surface 写目标与资源引用

模型界面 write 唯一顶层目标为 Surface，View 仅作为其中的操作目标，不另设独立 View 写入口。提交局部变更即可，无须重传整页；多 View 操作原子发布，沿用 Surface 及相关版本校验，不自动合并保守冲突。

HTML/CSS 的资源使用专门受控格式，由解析器鉴权并登记引用，不能从普通字符串猜测资源保留关系。引用任务数据遵守显式结构和预期版本；快照只固化明确声明的对象，不递归复制关联链，允许源业务数据存在循环引用。详见 [工具与资源](tools-resources.md)。

## 新增与事件的默认权限

主 agent Run 可在宿主允许位置新增 View，不默认获得已有内容或整体布局修改权。仅本 Run 新建且未被用户/他方改动的 View 可在该 Run 内继续完善，每次检查版本；输入/作答或他方改动后重新判断授权，不包含移除，资格随 Run 结束失效。丢弃输入仍本人确认。

View 事件提供来源/表单/版本上下文，不自动授予原 View 修改权。可新增反馈，但替换原内容和布局修改另行授权；单次批准只覆盖明确操作、目标、内容及必要版本，不生成永久或通配许可。见 [安全与审批](security-approval.md)。

## 表单提交不去重

每次明确且有效的提交创建新答案/事件，不按内容或客户端关联标识合并。界面提交期间禁用按钮减少误触，响应丢失不自动重发；原结果可按宿主 ID 查询，再次提交是新操作。格式校验、旧通道失效、版本检查与答案/事件事务保存继续适用，不移除这些约束。

## 已确认的 managed-v1 实现基线

小界面可直接在 write 内联 HTML/CSS、状态与行为，大内容引用同结构 bundle，经同一流程校验发布。不支持或不安全的语法拒绝本次发布、定位错误，不静默删除；宿主仅做契约公开的作用域、ID 和资源 URL 等机械改写。

保留语义排版、表格、基础输入、受限 SVG/MathML、受管理本地媒体/字体、flex/grid、响应式与局部有界动画。跨 View 采用 slot 内有序分组、单列/响应式多列，不能越界覆盖。行为独立列表绑定稳定元素 ID 和 JSON Pointer 固定字段，支持直接输入、文本、显隐、布尔切换、局部 class 切换和表单提交，不新增表达式语言。重复属性绑定拒绝，同字段兼容输入同步。

草稿保留输入原始值，正式答案同时保存原始与转换值；数值使用完整十进制/科学计数法、有限值与安全整数校验，不猜 locale、不 parseFloat 接受前缀。可选空数值省略，必填空值拒绝，文本不裁剪。草稿按状态版本保存局部字段；冲突留本地与远端供用户选择。500ms 防抖、持续输入最长 2s 尝试保存，每 View 一个在途请求；内存草稿不额外写浏览器本地库。

审批期间相关版本变化使旧 Action 结束为冲突，不自动改请求或沿用批准。精确结构与允许表草案见[managed-v1 契约](../contracts/managed-v1.md)，有界数值见[开发配置](../contracts/development-defaults.json)。

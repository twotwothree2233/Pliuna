# 内置代码执行：Monty

更新：2026-10-25。状态：用户已确认选型，完整接入与发布验收尚未完成。

## 选择与适用范围

首版内置代码执行 tool 采用 Monty，以原生后端作为当前集成基线，不并行建设 WASM 实现。已实测版本为 `@pydantic/monty@1.3.0`；接入时锁定包、平台运行时和完整性信息，升级后重跑契约测试。

工具对外定位为“受限 Python 计算工具”：适用于基础数值计算、文本和结构化数据转换，不承诺完整 CPython、任意第三方库、NumPy/pandas 或通用 Python 教学环境。能力描述必须公布支持范围，不能只写“Python 执行器”。

Monty 不承担任意插件后端执行、前端脚本隔离或整个 harness 的安全职责，也不要求引入 Pydantic AI。TypeScript 主体与自建 agent loop 保持不变。

## 已验证证据

原生包在 macOS arm64、Node.js 22.23.1 上通过 8 项冒烟检查，子代理执行后由主代理独立重跑：基础输入输出、跨次变量隔离、现存合成文件读取拒绝、环境变量拒绝、socket/subprocess 导入拒绝、执行时间限制、内存分配拒绝、打印输出上限。

详见 [实测报告](../research/monty-smoke-results.md) 与 [原型](../../prototypes/monty-smoke/README.md)。这些是具体行为证据，不是完整攻击测试、Electron 发布验证或安全保证。

## Tool 必须落实的配置与职责

- 每次调用创建新 session，只执行一次；关闭 session 并退役 worker。原生基线使用 `maxCheckoutsPerWorker: 1`，不向 agent 暴露持久会话或快照恢复。
- 不提供目录挂载、宿主文件/网络回调、外部模块、可调用宿主对象或任意工具派发接口。输入仅为获准的显式数据和字节。
- 固定可信运行时及二进制路径，不允许不受信任的环境变量或 PATH 替换执行文件。
- 限制源码、输入、执行时长、内存、递归、宿主往返、打印及最终返回总量；具体配额需集成实测，不能照搬冒烟参数当生产默认值。
- 设置完整调用的外部截止时间，覆盖编译、等待和返回处理；不能只依赖解释器执行计时。
- 成功、异常、超限、取消和保存失败都执行清理。超限 session 不得继续使用；取消后的迟到结果不得成为有效任务产物。
- 捕获打印并明确转换大整数、字节、集合和非有限浮点等返回值。验证输出后由环境外 tool 保存，不持久化执行目录。
- 沙箱不可用时明确禁用工具，不降级为宿主 Python、Node vm 或 shell。

## 安全边界与剩余风险

Monty 是语言级沙箱，不是操作系统级沙箱。关闭宿主能力时，解释器正常执行路径不提供宿主文件和网络访问；不能据此保证解释器漏洞被利用后仍有 OS 隔离兜底。原生 worker 子进程用于故障隔离，不是单独的权限边界。

内存限制是运行时分配计量，不是整个进程 RSS 硬上限。宿主输入输出缓冲、序列化、原生进程及其他开销仍需计量和控制。模块导入拒绝不等于已完成网络包审计。时钟、随机和等待策略须显式约定。

## 正式启用前的三个门槛

1. **部署**：Electron 打包后的干净 macOS 环境能运行，不依赖系统 Python/Rust/Docker；验证原生资产解包、可信路径、签名、公证及离线加载。
2. **生命周期**：验证取消、超时、崩溃和应用退出后的清理；无残留执行，旧运行结果不可保存；不能用吞掉 close 错误的冒烟脚本证明销毁成功。
3. **资源与权限**：补测权限绕过、输出总量、复杂返回、深递归、复杂源码和异常清理；明确非 RSS 硬上限的剩余风险，风险无法接受时不得宣称验收通过。

未通过门槛时可以继续其他 harness 开发，但代码执行能力保持未验收/不可正式启用。Windows、Linux 和 macOS x64 未实测，不因平台包存在就宣称支持。

## 重访条件

若出现必须支持第三方科学计算库、严格 OS 级隔离或进程总内存硬配额的需求，或原生后端无法满足分发和清理要求，应重新评估运行时/后端；不能通过开放宿主回调悄悄扩大当前工具权限。

## 返回值编码与非确定性

采用版本化带标签值编码：普通 JSON 保真、大整数为十进制字符串加类型、非有限值枚举、bytes 为资源引用及长度、tuple/set/frozenset 保留类型、非字符串键映射用 entries。标签外层封装避免与用户字典碰撞；循环/不支持值拒绝交付，不 repr/stringify 冒充原值，不自动重跑。见[输出 schema](../contracts/schemas/core.schema.json)的 wire_value 和[接入契约](../contracts/integration.md)。实际类型支持需 Monty wrapper 实测。

不承诺确定性或缓存同输入结果。宿主不额外提供时间/随机/等待回调，必要数据显式传入；Monty 自身时钟、熵和等待能力如实测试公布，不声称已禁用不可控行为。生产计算配额仍需专门集成验证，不直接采用普通插件时限。

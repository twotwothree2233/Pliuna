# 范围与需求

状态：产品范围已确认；验收步骤是推荐实现要求。更新：2026-10-25。

## 产品目标

Trellis 是单用户本地学习 agent 的 harness。用户输入目标与材料后，主 agent 可使用基础工具和已安装插件的能力，渐进式构建、更新可交互的任务前端。学习会话持续保存，但模型不需要持续运行。

“画布、画笔”仅是任务界面和呈现能力的比喻，不实现绘图编辑器，不限定 HTML Canvas，也不要求不同任务共用教学模板。HTML/CSS/JavaScript 是界面实现材料，不是唯一持久化对象。

## 首版交付

- Electron 桌面安装包；不要求用户安装 Node.js、Python、Rust 或 Docker。运行沙箱仍待验证，不因无 Docker 而直接执行宿主代码。
- macOS 开发与验收；平台相关路径、凭据、进程和执行实现集中封装。Windows、Linux 保留适配可能，但未验收前不宣传可用。
- 可配置模型服务、主 agent 和审批模型角色；两个角色可使用同一服务，但上下文独立。
- 通用自主执行：理解目标、读取材料、发现能力、调用工具、构建界面；无 workflow 也可运行。
- 多格式输入的接纳、保存和按需读取；不内置统一全量转换流水线。
- 插件包发现、校验、激活、权限和工具接入机制，以及验证这些机制的最小测试夹具。
- 会话、界面、交互和工具输出持久化，关闭后可恢复；支持用户删除任务及其关联资源。
- 在线交互为主，按需导出自包含静态 HTML；无自定义脚本或学习交互，不重新生成整套材料作为默认路径。完整材料生成另行发起 Run，详见 [导出契约](export.md)。

## 明确不做

实际学科插件、插件构建 agent、插件市场、多用户账户、多租户、协作编辑、云端调度、子 agent 系统、自动下载插件、结构化教学工作流引擎、完整文件格式解析套件和通用前端交互语言。

不能因为“插件是未来功能”而省略 harness 的插件接入契约；也不能为了验证协议就开发一套真实教学插件。

## 用户主路径

1. 配置模型服务和审批模式，创建任务，输入目标并显式添加材料。
2. 主 agent 发现当前可用能力。不存在适用插件时仍可执行基础任务；能力缺失时明确说明。
3. 运行期间逐步发布界面。用户可以阅读、输入、执行本地交互或发出需要 agent 的事件。
4. 需要审批时展示操作与范围，按模式手动处理或交给独立审批调用。
5. 用户可取消执行、关闭应用并重新打开任务；历史不会因执行环境销毁而消失。
6. 用户按需导出、重新开启已结束任务或删除任务。

## 用户可见的失败行为

缺少能力、模型错误、资源读取失败、界面校验失败和沙箱不可用必须明确显示。旧界面在新版本发布失败时保持可用。不得默默退回宿主执行、放宽网络权限或丢弃用户输入。

模型服务请求需要联网；“执行环境和生成页面禁止网络”不等于整个应用离线。向服务提交材料前应明确展示使用的服务与数据处理范围；任务数据本地保存不意味着数据从未发送给模型提供方。

## 完成标准

无真实插件时可以完成目标输入、基础工具调用、渐进界面和交互恢复闭环。通过测试夹具验证插件发现、权限、工具调用与越权拒绝。任务重启后恢复已提交状态；运行中的外部效果不会被盲目重放。独立材料导出明确标记缺失内容。

代码执行能力只有在具体沙箱通过验收后才能标记为可用；其未决状态不妨碍先完成其他模块，但不允许用假实现宣称首版全部完成。

## 本轮接入范围补充

插件是人工确认信任的本地程序，不承诺恶意插件 OS 隔离；Monty 只限制内置计算工具。首版实现静态注册、任务级/全局级、人工信任确认、双向 JSON-RPC over stdio 和统一动作审批，不实现依赖自动安装或 MCP 兼容。

Task 长期保存，停止生成仅取消 Run，不取消无关插件独立动作；显式停止任务则关闭整个任务的业务执行。切换任务或关闭页面不停止执行。停止任务会停止任务级插件，应用全局插件可继续运行但不能修改该任务。任务范围/实例管理是接口控制，不保证限制插件自行文件访问或删除其已有副本。

## 界面与数据恢复范围

普通呈现使用 HTML/CSS 和受限行为/状态声明，以单元整体替换；草稿自动保存、显式提交生成不可变答案，允许多表单独立字段范围。草稿可不完整，提交校验不等于教学评分。

首版以当前状态恢复，不做事件溯源；重启不自动继续执行。文件导入副本、不可变版本、保留已发布界面历史，历史只读不执行脚本。任务删除人工确认永久执行，不做回收站；已确认清理中断后继续。具体契约见 [存储与恢复](storage-recovery.md)。

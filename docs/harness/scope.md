# 当前范围与使用路径

Trellis 提供单用户、本地优先的任务工作空间。
每个任务保存指令、回复、材料、界面和执行记录。
模型与插件通过宿主接口处理任务。

## 已接入的功能

| 范围 | 当前行为 |
| --- | --- |
| 任务 | 新建、查询、停止、恢复和删除 |
| 请求 | 保存材料绑定、排队、取消及显式解决冲突 |
| 模型 | 渠道配置、模型发现、角色测试和请求用量 |
| 内容 | 保存回复、版本化界面、结构化数据和作答 |
| 材料 | 文件/文本导入、分段阅读和派生来源 |
| 插件 | 固定包、信任、依赖检查、启用和流程选择 |
| 计算 | 通过平台门槛的 Monty 一次性执行 |
| 导出 | 内容选择、后台预检、预览和受控 HTML 保存 |
| 存储 | 恢复点、只读检查、暂存与正式资源清理 |

## 一条常见路径

1. 新建任务并配置主模型渠道。
2. 显式测试并启用所需模型角色。
3. 添加材料，等待导入结果或解决部分失败。
4. 提交指令，查看队列和本次执行动态。
5. 按具体动作完成审批或输入丢弃确认。
6. 阅读保存内容，按需导出或维护存储。

配置模型和插件不会自动启动任务。
导入文件也不会自动发送正文给模型。
材料使用由当前请求和显式工具读取决定。

## 当前边界

- 任务界面仅启用 managed-v1。
- 任意脚本和嵌入网页不进入任务 View。
- 插件本地代码运行在用户信任边界内。
- PDF 参考能力只提取纯文本，不提供 OCR。
- Monty 使用受限 Python 能力，平台门槛独立存在。
- 应用重启恢复数据，不续跑旧业务执行。
- 本地任务数据在调用模型时可按请求外发。

# 当前材料导入与读取

导入将用户选定内容保存为同任务不可变资源。
导入、解析和模型读取是分别触发的操作。

## 导入来源

用户可选择一个或多个文件，或添加明确的文本材料。
来源路径由主进程取得并固定身份。
Renderer 不直接读取任意本机路径。

传输按固定长度分块，宿主核对 offset 和累计体积。
已注册的导入拥有独立 operation_id。
批次逐文件提交，允许部分成功。

纯文本使用严格 UTF-8 处理。
其他文件保存原始字节及通用媒体类型。
源文件变化、不安全链接或超限会导致明确失败。

## 与请求队列绑定

请求可引用已保存资源及尚在导入的操作。
队列等待全部关联导入得到结果。
失败后由用户选择成功材料或替换原导入。
重试创建新导入，并保留 retry_of 关系。

重新选择模型或材料后，启动前再次校验。
旧请求不会因为默认模型改变而偷偷换配置。
运行中读取只使用任务允许的资源。

## 阅读与定位

文本正文支持字符预算和分页游标。
用户界面还可指定 UTF-8 字节范围。
模型可按行、工具报告页索引或字面搜索读取。
具体接口见[工具与资源](tools-resources.md)。

原始 PDF 不直接当作文本阅读。
PDF 提取通过明确启用的参考能力执行。
派生结果保存成新文本资源，再按需读取。

## 派生来源

宿主绑定原件资源、能力、调用及输出资源。
页索引和 partial 标记按工具返回记录。
材料导入成功与文本提取完整分别判断。
空文本、密码、加密和解析错误有独立错误码。

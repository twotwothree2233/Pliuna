# 多格式输入与材料解析

状态：本轮整批行为已由用户确认，尚未实现。预览方向、读取范围及开发资源配额已确认；能力来源/批次字段及具体渲染实现仍待完善。

## 导入与处理分开

单独导入默认只做基础工作：将文件复制到受控存储，检查大小、识别基本类型、计算内容摘要并登记资源。不自动启动 Run、解析插件、OCR 或模型调用，不自动发送全文到模型服务，不执行文件中的脚本、宏或外部链接。“已导入”仅代表保存成功，不代表已解析、已发送或已理解。

用户附文件并发送明确请求时，在附件导入完成后开启或排队 Run，agent 根据请求按需读取或调用已有解析能力，仍遵守工具授权规则。没有适合能力时明确报告，不自动安装插件，也不声称读过材料。单独导入不启动插件处理，不改变已启用可信插件自身的进程生命周期或注册读取范围。

## 首版内置入口

- 用户选择或拖入一个或多个文件，每个文件独立登记，不自动合并为一份材料。
- 用户明确选择“添加为材料”的粘贴文本保存为文本资源；普通聊天输入仍是消息，不自动重复建立资源。
- 粘贴网址只提供链接，不代表已获取网页；首版不内置网页抓取。需要时由已启用的相应插件按明确请求处理。
- 文件夹不递归扫描，提示选择具体文件，避免无意导入隐藏文件、凭据和大量无关资料。
- 压缩包可以保存，但不自动解包；读取内部内容需要相应工具能力。

这些是 harness 内置入口的边界，不限制插件既有扩展能力，不把 Monty 禁网约束扩大到可信插件。

## 多文件批次与请求提交

逐文件校验、保存和登记，允许部分成功，不做整批回滚。成功文件立即成为可用资源，不因其他项失败而删除；未完成文件不得登记为有效资源，临时数据按既有存储规则清理。

逐项显示等待、导入中、成功、失败或取消，不能只用一个“完成”掩盖失败。取消停止未完成部分，已成功项保留；界面重试只重试失败项，不重新提交成功项。具体状态编码和操作关联字段待定义。

附文件的请求等待导入结束；任何附件未成功时，默认不启动该请求的 Run。由用户明确决定仅用成功文件继续，或补齐后再发送，不能静默减少材料范围。补齐后仍遵守每任务一个未结束 Run 的排队规则。独立导入的部分成功不自动触发推理。

## 能力声明与选择

解析能力复用既有插件工具发现、调用与授权协议，不新增独立解析插件执行机制或复杂调度引擎。声明支持的输入类型、操作、输出形式及重要限制；支持 PDF 文本提取不意味着支持扫描页或公式。

主 agent 按任务需求与能力描述选择，不按扩展名强制固定流程，不默认把所有候选工具执行一遍。确有需要时可组合调用，但费用、数据外发或结果取舍存在尚未明确的关键差异时，应说明并向用户确认；权限审批不能代替需求选择。

失败先记录原因，替换工具仍需符合原请求、权限和剩余预算，不静默扩大处理范围。插件声明不构成对其 OS 行为的强制保证，可信本地执行边界保持不变。

## 派生资源、来源与复用

解析结果保存为关联原件的派生资源，记录原始资源确切版本、所用工具或插件版本及影响结果的参数。原件重新导入或变化后，旧解析不能冒充新版本的结果。

仅保留实际提供的页码、段落、时间戳或单元格定位；部分成功、截断、识别失败和能力局限明确标记，不伪造精确来源。定位与来源字段具体编码待定义。

Agent 可以查询已有派生资源并判断是否足够回答问题，避免重复解析。来源、版本和参数相同只说明可能可复用，不保证完整或适合当前任务；首版不做自动替代工具调用的通用缓存引擎。重新解析产生新结果，不覆盖旧结果或破坏既有引用；插件升级不自动触发全量重解析，不建设自动刷新流水线。

## 有界返回与分段读取

大解析结果先保存为资源，工具直接返回有界的处理状态、结果引用、可用定位与必要预览，不把全文塞入工具响应。正文通过基础读取能力按段落或字符范围获取；只有实际存在页码、章节等索引时才支持该类定位，不要求 harness 理解学科结构。

每次读取明确当前片段范围、是否还有后续内容及继续读取方式，不让截断看起来像全文。资源 ID 不授予访问权，仍检查任务与主体权限。

仅向支持视觉输入的模型按需提供图片或页面，不自动把全部页面转换发送。转换由对应能力完成，并遵循请求、预算与授权规则。首版不为此强制引入向量数据库或复杂语义检索流水线，复用资源列表、目录信息和范围读取。

## 惰性资源与受控预览

导入资源默认是数据，不因扩展名或用户提供文件就获得执行能力。代码不自动运行，文档不执行宏，HTML 不直接挂入任务 DOM。文本按文本展示，其他类型仅经明确支持的受控预览路径打开；HTML、SVG 等活动格式需安全处理或转换后才能预览。

预览不自动加载远程图片、字体、链接目标或嵌入对象。不能安全预览时可保存成功并标明暂不支持预览，不把保存与预览结果混为一谈，也不通过直接执行原文件来降级。

用户 HTML 转为任务界面仍经过既有校验、范围授权和发布入口，自定义脚本仍需隔离。查看与运行分开，具体执行请求沿用相应工具契约；不影响学习代码、阅读网页源码或可信插件在既有信任边界内处理材料。

## 未决项与验收

预览复用有效呈现 profile，范围读取与开发导入配额已确认；仍需逐格式验证、来源/批次/重试关联字段和安全实现。尚未选择通用解析依赖，也未开发真实解析插件。

验收覆盖导入不执行或外发、附请求附件不全先确认、部分成功与取消、派生版本与来源、读取截断、缺能力提示，以及恶意活动内容与远程引用的受控预览。文件存储沿用 [存储与恢复](storage-recovery.md)，权限沿用 [安全与审批](security-approval.md)，具体场景见 [测试计划](testing-delivery.md)。

## 模型侧读取与查找

list 仅提供已定义字段筛选及名称/简短描述等元数据匹配，明确范围，不以元数据未命中推断正文无内容。模型 read 只读取已有文本/结构化表示和受支持图片；其他格式先返回元数据及已有派生引用，不隐式解析或转换，不向模型灌入大段二进制/Base64。需要处理时经 call 显式执行已有能力。

分段 read 检查版本，变化即中断当前续读，放弃本轮旧片段并从最新内容重读；重读有预算上限，不混合版本。不可变原件及派生版本引用仍不可变。见 [工具与资源](tools-resources.md)。

## 预览不削弱前端表达

预览复用当前启用且已验证的前端呈现 profile，不限定为纯文本和静态图片。HTML/CSS 可实际呈现但须校验；图表、公式、媒体和本地字体按有效能力展示，脚本只能进入独立隔离区域，未完成隔离不得退回共享 DOM。

查看材料不自动执行材料代码、宏或插件，不隐式解析/转换；PDF/Office 等经已有渲染能力或插件派生表示展示。只有无可用能力时回退元数据/源码并说明缺口，不因此增加全格式解析器。单个导入/上传资源开发上限 256 MiB，见[开发配置](../contracts/development-defaults.json)。

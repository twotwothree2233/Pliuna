# 独立学习材料导出

状态：导出行为、片段结构及开发上限已确认；schema 已有草案，静态呈现和跨平台保存仍待实现验证。

## 范围与格式

首版唯一正式导出格式为自包含、可离线阅读的单文件静态 HTML。不依赖 agent、插件、宿主或旁边的资源目录，不携带自定义 JavaScript，不运行模拟器。移除提交答案、调用 agent/工具等入口；折叠内容转换为展开的可读内容。允许目录跳转、普通链接、浏览器搜索和打印等基本阅读操作；普通外部链接不代表其目标内容已离线打包。

保留指定版本已有的文字、图片、公式、表格和复杂区域提供的静态表示。样式、图片及必要字体嵌入文件，公式与图形使用无脚本表示；不依赖 CDN 或远程资源加载。首版不并行建设 HTML 加资源目录、ZIP 或 PDF 导出实现，浏览器打印不等于已提供专门 PDF 适配。

导出不重新调用模型、插件或工具补齐内容，不执行旧脚本；宿主仅进行受控转换、校验与打包。渐进式任务尚未生成的章节不自动出现。“生成完整材料”、补充静态表示或重写讲义是用户另行发起的 Run，单独消耗预算，完成后再导出，不要求必须安装插件才能提出该请求。

## 导出范围与个人内容

默认导出学习材料，不附带个人作答、评分或学习评价。用户明确选择后可加入已提交的答案及已有对应反馈，必须绑定当时题目版本，不将旧答案拼到新题。尚无的评分、解析或反馈保持缺失，不调用模型补齐。

始终排除未提交草稿、审批记录、工具日志、内部标识及凭据，不序列化整个任务状态。仅打包选中内容实际使用的资产，不附带整份原始资料、隐藏状态、历史对话或其他任务数据。导出选择使用的内部关联信息用于宿主校验，不作为材料内容输出。

正文或图片中已经出现的姓名、个人经历等可能仍被带出，关闭“包含作答”不等于自动脱敏。导出前展示范围与预览，明确提醒用户检查，不承诺自动识别所有隐私。

## 显式分类与导出片段

内容生成时声明学习材料、正式作答或个人反馈等类别；普通内容和复杂区域的静态表示遵循同一规则，不在导出时用关键词或模型临时猜测。字段草案见[managed-v1 契约](../contracts/managed-v1.md)。

同一 View 可以混合展示题目和反馈，但应提供可分别选择的导出片段，不强制每一类拆成独立 View。混合且无法拆分的片段整体按包含个人作答/反馈处理，默认内容版不纳入并明确提示。

未分类片段不能默认为安全，进入完整性问题清单；用户可返回任务补充分类，或确认带遗漏提示的部分导出。Harness 检查声明结构与选择规则，不能仅凭分类证明插件声明正确或内容无隐私。按用户选项正常排除个人内容，与未分类/损坏导致的异常遗漏应分别展示。

## 快照、预览与权限

开始导出时固定选中呈现单元、内容版本、资源版本，以及选择附带的正式作答和反馈。预览与最终文件使用同一快照；任务继续交互和更新，不冻结整个任务，新增内容不自动混入。

用户希望包含新内容时明确刷新快照、重新预览，必要时重新确认遗漏。引用资源不可用时按完整性失败处理，不替换为最新版本或相似材料。快照固定内容而不固定授权；任务删除或导出权限失效后，未完成导出停止。

## 完整性与体积

导出前列出缺少静态表示、资源缺失、无法安全转换及未分类等问题。默认阻止完整导出，不重新执行脚本或调用模型补齐，不以“成功”掩盖遗漏。

允许用户本人明确确认部分导出，“帮我批准”不能代办。文件在对应位置注明“此区域未导出”及简短原因，并附遗漏清单，接收者无需访问宿主即可知道材料不完整。修复原内容或静态表示是另一个操作，完成后重新导出。

导出前估算文件大小；超限时明确提示用户缩小范围，不能静默省略图片或改成远程链接。开发上限见文末配置，仍待测试校准，不以部分导出确认作为绕过体积限制的方式。

## 受控保存、覆盖与取消

保存位置由用户通过系统文件对话框选择。Agent 只能建议文件名，生成内容和插件不能自行指定宿主写入路径或据此获得任意文件访问能力。该宿主保存能力不改变 Monty 无宿主文件、无网络、单次运行的约束。

目标已存在时，覆盖必须由用户本人明确确认，审批模型不能代办。先在后台生成并校验临时文件，再使用平台支持的安全替换方式完成保存。失败保留原文件，不把半成品当成成功；不承诺所有文件系统下的绝对原子性。具体替换、竞争检测和崩溃恢复机制需平台验证。

取消未完成导出时清理临时产物，不交付残缺文件。最终文件已成功保存后再取消，不自动删除它；最终发布与取消/撤权的竞争需明确实现边界并测试。保存成功不能只依据临时文件已生成。

导出副本脱离任务管理。之后修改或删除任务不会自动更新、撤回或删除用户保存的 HTML，不保证收回已分发副本。

## 未决项与验收

分类/片段 schema 和开发体积限制已有草案；静态表示验证、快照引用保护、保存替换和异常恢复仍待实现。macOS 优先验收，未经实测不宣称 Windows/Linux 或任意文件系统已通过。

验收需要覆盖无脚本/无自动外联、离线打开、默认排除作答、版本绑定、分类缺失、混合片段、缺失表示、部分导出本人确认及文件内标记、快照更新竞争、删除/撤权、覆盖确认、磁盘失败与取消。详见 [测试计划](testing-delivery.md)、[任务界面](surface.md) 和 [存储与恢复](storage-recovery.md)。

新发布的自定义脚本区域必须具有最低可读静态表示，见 [任务界面](surface.md)；这不等于已满足导出分类或完整性要求。此处缺失处理仍覆盖存储损坏或不完整内容，不构成允许缺少静态表示发布脚本区域的例外。

## 片段结构与离线媒体

导出片段使用稳定 ID、类别和本 View 元素 ID，或提供单独受限静态片段；不允许自由选择器或执行代码抽取。元素根重复/祖孙重叠拒绝声明，要求明确拆分或提供独立内容，不猜分类删子节点。精确结构见[managed-v1 契约](../contracts/managed-v1.md)。

允许将已有且明确选中的音视频内嵌到单文件并使用浏览器原生控件播放，不允许自动播放、自定义 JavaScript 或学习提交，不自动转码。播放属于阅读消费，不构成在线学习交互。超限/编码不支持/资源缺失进入完整性处理，不自动补生成。导出成品开发上限 256 MiB，最终支持仍须真实离线浏览器验证。

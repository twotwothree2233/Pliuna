# 测试与实施计划

状态：技术与夹具范围已确认；交付顺序是推荐计划，尚未执行。

阅读提示：实施顺序见[建议交付阶段](#建议交付阶段)，契约缺口集中见[开发契约缺口](../development-readiness.md)。本页后续按主题列出验收场景；“新增”仅表示访谈追加的来源，不表示已实现或另有一套规则。行为定义以相应专题为准，执行测试时再记录通过情况。

## 测试范围

Vitest 验证协议、权限、状态、调度与 agent loop；Playwright 验证 Electron 关键交互。模型默认模拟流式碎片、错误、取消和格式异常；真实模型仅为可选检查，不要求每次测试消耗 token。

最小插件夹具包括流程说明、模拟工具执行端、合法与越权呈现请求、缺失依赖和不兼容 manifest。它们只验证契约，不演变成真实学科插件、课程或市场。

| 领域 | 必测行为 |
| --- | --- |
| 协议 | 拒绝无效消息、类型无漂移、不支持能力明确失败 |
| Loop | 无 workflow 可运行、单未结束 Run、审批等待释放模型但不冻任务、预算耗尽停止 |
| 流程 | 加载说明但没有领域状态机；说明不授予权限 |
| 审批 | 两种模式、独立上下文、无效响应转人工、参数变化失效、硬禁止不可批准、意图确认不可代答 |
| 资源 | 级别查询、同任务跨插件共享、宿主秘密排除、分页与截断 |
| 普通界面 | 活动内容拒绝、CSS 作用域、基础行为不执行任意 JS |
| 自定义界面 | 禁止外联、父 DOM/Node/凭据访问、旧通道失效、故障恢复 |
| 发布 | 批量原子性、版本冲突、独立请求登记、草稿不丢失 |
| 持久化 | 重启恢复、孤立资源回收、删除撤销访问 |
| 取消 | 旧 run 不能写入、未知副作用不重放 |
| 导出 | 无宿主依赖、缺失明确报告、私有状态不混入 |
| 平台 | 干净 macOS 安装、无系统 Node/Python/Docker、离线资产 |

Monty 与前端的文件、进程和网络限制必须在对应真实隔离端负面测试；可信本地插件只验证接口授权和生命周期，不承诺 OS 沙箱，不能仅用 mock。截图和页面无报错不证明安全。

## 建议交付阶段

### A. 文档与机器契约

将协议草案变成 JSON Schema，选择类型生成工具，验证示例和生成类型；保留未决清单，不虚构沙箱实现。

### B. 桌面与持久化

最小 Electron 主进程、React 宿主、后台 runtime、SQLite、资源和凭据接口；验证创建、重启恢复、删除与日志脱敏。

### C. 通用 agent 闭环

模型 adapter、单主 loop、模拟工具、上下文和预算；无插件完成基本任务。加入手动与独立模型审批，验证批准绑定与失效。

### D. 界面与插件接入

统一 DOM 受控呈现、基础交互、暂存发布、事件恢复；插件目录与测试夹具。自定义脚本隔离通过后才开放，不降级到宿主 DOM 执行。

### E. 代码沙箱验证与接入

Monty 已确认选型，原生后端为集成基线。已完成 [原生包快速检查](../research/monty-smoke-results.md)，后续按 [三个启用门槛](code-execution.md) 完成部署、生命周期及资源权限验证。验证前不宣称代码执行可正式交付；不并行开发 WASM 后端。

### F. 首版验收

通过契约测试、Electron 关键路径、导出和 macOS 发布检查。报告平台、配置、限制和实测指标，不宣称未经测试的跨平台支持或绝对安全。

## 完成定义

阶段以可验证行为完成，不以目录存在完成。沙箱集成验收未完成不阻塞 A-D 的无代码执行路径，但不能隐藏未完成的代码执行能力。无需真实教学插件作为交付条件，夹具验证不同布局和越权行为即可。

## 本轮新增验收场景

- 信任确认前不启动进程；代码/启动配置变化重新确认；全局启用不能模型代批。
- 任务级读取同任务其他插件业务数据成功，跨任务拒绝；全局查询成功但凭据查询拒绝。
- 任务级动作跨任务即使被模型批准也拒绝；全局单动作只目标一个任务。
- 所有 View 归任务，插件停用不转移归属；未经授权的修改拒绝。
- 工具派发前授权，结果新修改再检查；插件后端 OS 行为不被误宣称受沙箱限制。
- 工具等待期间插件反向查询、响应及取消正常工作；待审批不占任务写队列。
- 无 Run 的插件动作可审批执行；waiting Run 仍阻止第二个 Run，但不阻塞其他获准动作。
- 取消 Run 使其审批失效，不误取消独立插件动作；版本变化在执行前重新检查。
- 关闭页面不停止执行；显式停止任务停止任务级插件，全局实例保留只读但不能修改该任务；取消宽限后终止、后续按需启动符合约定。
- JSON-RPC 关联 ID 与宿主操作 ID 分开，不提供业务去重；通知不冒充需要确认的修改申请；大消息和日志有界。

这些均为 harness 与最小测试夹具的契约验证，不需要开发真实学科插件。

## 界面状态与存储新增验收

- 单元替换不重建整页；行为目标仅本单元，禁止任意脚本/表达式和全局选择器。
- 多表单提交只包含声明字段；不完整数值文本可保存，格式无效提交不生成事件。
- 作答快照与事件事务一致；多次提交独立登记；新草稿/换题不改变历史答案和资源引用。
- Preserve 同时检查 schema、兼容标识和状态版本；换题不能因 answer 同名继承，reset 丢弃输入必须本人确认。
- 替换期间新增输入不会被覆盖，保存失败状态可见；突发崩溃不声称未保存按键已持久化。
- 重启未确立结束边界的 Run 按中断收尾，已确立边界的保留原因；无自动模型/工具调用，旧审批入口无效，用户继续创建新 Run。
- 导入后修改或删除源文件不影响历史资源；重新导入形成新版本。
- 文件保存后数据库失败允许孤立文件；回收不删除进行中保存；登记文件缺失/损坏明确报错。
- 插件返回路径不触发宿主读取；分块上传受授权/总量约束，取消后无可引用半成品。
- 历史页面不执行脚本、插件或模型；静态表示缺失有提示，表单不可再提交。
- 删除先撤销后清理；中途崩溃继续清理，不恢复任务；共享资源保留，外部副本不宣称已收回。

上述均为待实现的验收契约，当前文档检查不等于行为测试通过。

## 上下文管理与模型中断新增验收

- 请求预算含宿主规则、工具定义、材料、摘要、完整近期交互、输出与误差预留；先按需装载/确定性缩减，再语义压缩。
- 保持调用/结果完整组；在安全边界同步整理，无并行后台摘要；页面交互和草稿保存继续，新输入不被快照覆盖。
- 摘要请求无工具权限、默认主模型且上下文独立；另配模型检查容量/格式，跨服务发送明确告知，不静默降级。
- 压缩调用/token/耗时计入 Run，预算不足停止；格式或长度错误最多纠正一次，认证错误/取消不纠正。
- 候选为空、引用不存在或跨任务、覆盖范围不符、请求仍超预算时不安装；保留旧摘要与原始记录，取消后迟到结果拒绝。
- 多次增量压缩保留未完成请求、用户纠正、来源与未知执行状态；学习判断不变成事实，摘要批准不变成有效权限。
- 插件保留说明有界且仅当前任务相关；冲突优先通用结构，无专用压缩执行 hooks，不靠摘要保存精确业务数据。
- 大单项输入不触发无限压缩；错误区分服务、预算、单项过大与校验失败，不静默丢弃请求。
- 自动整理状态与摘要详情可见；手动整理不打断工具、不授权业务动作，无 Run 时仅整理 Run 完成即结束；纠错回查原记录。
- 流式残缺工具参数不派发；部分输出断开中断 Run、保留已提交结果，用户继续新建 Run；结果未知不自动重试。
- 无任何输出的暂时性模型错误才允许预算内有限重试；认证/参数错误直接提示，不自动重放整个 Run。

使用多轮纠错、长期学习记录、注入内容与版本变更等夹具评估来源准确性、未完成请求保留、事实/推断混淆、重复执行风险、回查成本及缩减率。具体阈值待实验；结构校验通过不等于摘要语义正确，详见 [上下文管理](context-management.md)。

## 静态导出新增验收

- 单个 HTML 离线打开，必要资产内嵌，无自动外联、自定义脚本、宿主桥接或学习提交入口；折叠内容展开，目录与浏览器阅读操作可用。
- 导出只打包选中资产，不附带原件全集、隐藏状态、其他任务、草稿、日志、内部标识或凭据；不调用模型/插件/工具补齐内容。
- 默认无个人作答/反馈；显式选择后绑定原题版本，缺失评分不生成，个人内容在正文/图片中的残留风险有提示。
- 同 View 分类片段可分别选取；不可拆混合片段默认排除并提示，未分类阻止完整导出，分类错误不被宣称自动识别。
- 静态表示缺失、资源损坏/缺失或转换失败阻止完整导出；部分导出需本人确认，成品对应位置与清单均标明遗漏。
- 超限明确提示缩小范围，不静默丢图或转远程链接；体积上限待实测。
- 预览与成品固定同一快照，任务中途更新不混入；刷新需重新预览，缺失旧资源不拿新版本代替。
- 任务删除/撤权停止未完成导出；快照与保存过程中资源回收、取消、撤权的竞争需真实测试。
- 系统对话框选择路径，插件/内容不能指定任意路径；覆盖本人确认，磁盘满/权限错误/替换失败不损坏原文件或报告成功。
- 取消清理临时产物，成功后迟到取消不删除文件；任务删除不撤回导出副本。

保存与静态表示安全需要真实浏览器、文件系统和平台测试，不能只依赖 mock。当前只确认验收要求，未实现或执行这些行为测试。详见 [导出契约](export.md)。

## 输入与解析新增验收

- 单独导入不启动 Run、解析插件、OCR 或模型请求；状态不混淆保存、解析、发送和理解。
- 文件逐项登记，粘贴材料与普通消息分开；网址不抓取、目录不递归、压缩包不自动解包。
- 多文件部分成功可见，取消保留成功项并清理临时项，重试不重新提交成功项；失败项不形成有效资源。
- 附件未全部成功的请求不启动 Run，用户明确部分继续或补齐后才进入正常排队。
- 多候选解析工具不默认全部执行；能力局限可见，关键费用/外发/取舍先确认，缺能力不虚构结果或安装插件。
- 派生来源、能力版本和参数可追溯，原件变化不误用旧结果，重新解析新建资源，升级不触发全量处理。
- 部分成功、无定位、识别失败和截断明确显示；大结果有界响应并可范围续读，图片不全量自动转换发送。
- 代码、宏、HTML/SVG 活动内容和远程引用不因导入/预览执行或自动外联；不支持预览仍能保存。
- 用户 HTML 发布不绕过共享 DOM 校验或脚本隔离；预览安全用真实渲染路径负面测试，不能只依赖 mock。

上述是待实现的契约测试，不要求真实解析插件，可用最小能力夹具验证；预览白名单、配额与协议字段仍待定义。详见 [输入处理](input-processing.md)。

## 模型服务与调度新增验收

- 服务模型列表、目录候选及账号可用性分开；服务元数据优先，缺失补全、来源可追溯，关键缺失/冲突仅要求局部手动配置，无猜测性容量兜底。
- 自动目录查询不发送任务材料/密钥到第三方目录；用户主动测试采用有界合成内容并提示费用，不遍历全目录或测试窗口极限。
- 主模型工具/流式能力按测试确认，失败不从普通文本执行命令；审批/压缩仅要求相应角色能力，变更后旧测试不被误用。
- 失败不自动切换模型、渠道或凭据，新 Run 重新检查能力/容量；真实任务数据不静默发往其他服务。
- 未结束 Run 和已调度独立请求锁模型及渠道，包含等待审批/排队/本地工具阶段；多占用者分别释放，取消与锁释放无竞态绕过。
- 占用中渠道密钥/地址不可修改删除，同渠道未占用模型独立参数可编辑；自动目录更新不能绕锁。
- 尚未启动任务请求不锁配置但保留选择，启动前复核；配置变化先确认，默认模型变化不替换排队选择。
- 目录刷新不覆盖手动值；价格更新不改预算或历史估算；目录故障不阻断已有已验证配置。
- 所有模型角色与连接测试受并发上限，跨任务公平排队；等待审批不占请求名额但保留配置占用，排队取消后不再发请求。

具体配置 schema、模型匹配、必需参数、测试判定、并发/队列限额和真实服务兼容性尚待定义/验证。上述均是待实现要求，见 [模型服务](model-services.md)。

## 任务停止与恢复验收

- 切换任务或关闭页面不取消 Run，待审批仍可从统一入口访问；取消单 Run 不误取消无关插件动作。
- 停止与提交竞态按统一写入顺序处理：边界前提交保留，边界后旧结果拒绝；全部未启动请求、未完成动作及审批失效，含无 Run 动作。
- 停止时取消模型/工具、卸载脚本并停止任务级实例；全局实例只读允许、业务修改拒绝；外部结果未知不宣称已回滚。
- 清理未完成或异常时状态真实，“停止中”不可恢复，不出现新旧实例交叠。
- 停止期间基础输入和答案仍可保存且每次明确提交独立登记，不触发模型/工具、不积累自动执行队列；历史页面仍不可提交。
- 缺少静态表示的脚本区域发布失败，旧界面保留；合格静态表示供停止、加载失败和历史使用，损坏有明确提示。
- 打开已停止任务不恢复，显式恢复不调用模型或重放旧执行；脚本重新初始化只加载兼容状态，不自动提交，插件代码变化需重新确认。
- 应用重启不解除已停止状态、不自动续跑。上述为待实现契约测试，尚未执行真实运行时验证。

## 插件选择与配置验收

- 纯内容包通过静态校验即可发现，无启动命令、解释器或握手；可执行部分未经信任不得启动，前端脚本不因无后端而绕过校验。
- 混合包执行能力不可用时，仅提供依赖满足的独立内容能力，明确局部不可用，不绕过插件整体必需依赖。
- 安装不自动启用，新任务仅基础能力；agent 可看静态摘要并建议，但未启用正文不可加载。
- 类型分类中的同一插件共享整体启用状态，卡片展示能力/级别/执行/依赖；主 workflow 单独选择且至多一个。
- 启用不立即加载全部正文、启动进程或执行工具；全局启用不伪装成任务勾选，也不向所有任务自动注入流程。
- 未结束 Run、审批等待和插件动作/调用阻止普通配置变更；全局更新等待相关占用全部释放。
- 紧急停用立即生效，依赖执行取消、迟到结果拒绝、已保存内容保留；主流程选择清除而不自动替换，全局影响可见。
- 配置变化不创建 Run、不改历史；上述为待实现要求，当前未执行 UI 或运行时测试。

## 插件依赖与转调验收

- 必需依赖一次列明原因和范围后确认启用；缺失、版本冲突及声明依赖环阻止相关能力，不自动安装或启用可选依赖。
- 全局/代码执行依赖显式确认，依赖解析不绕过配置占用或主流程选择；停用显示影响、取消依赖执行且保留内容。
- 跨级转调保留真实来源和目标任务，不能借全局工具获得越界资源引用/修改权；独立全局动作仍按原范围处理。
- 当前链自身调用、A→B→A 均直接拒绝而不排队；插件伪造/清除调用链不能绕过。
- 无环链触及深度、调用次数或时间限额即受限；取消沿关联执行传播，转调不重置预算，无 Run 动作同样受限。
- 查询/响应/取消消息不被工具执行阻塞；上述是待实现测试；嵌套转调忙碌即拒绝的跨链验收见下节，不声称已消除插件内部或外部系统的所有死锁。

## 无业务去重与提交事务验收

- 相同内容的新 write/动作/事件分配不同宿主 ID，分别授权和版本校验，不复用原结果，无客户端去重键、参数摘要或 1 小时窗口。
- 相同有效答案多次明确提交形成不同记录；提交期间按钮禁用，响应丢失不自动重发，原 ID 查询不创建新操作。
- 同事务保存业务变更、业务记录/引用和 Action 成功结果；任一事务失败不出现部分数据库提交，文件孤立产物按既定规则清理。
- 提交后注入响应失败，原 Action 仍成功，客户端查询/版本同步可恢复；再次提交独立处理，可能版本冲突，不自动返回旧成功。
- 原动作终态不复活，已发布草稿不可重复发布，许可/版本控制不因删除去重而取消。上述运行时测试尚未实现。

## 核心契约制品验收

已有[契约验证脚本](../contracts/verify.py)、正反例与临时 SQLite 结构检查；执行输出记录其真实范围，不将它们当作运行时验收。
